About JSON compare

Find the real differences between two JSON files or API responses. Fileutilo compares the structure, so different spacing or key order doesn't show up as noise. Your files are processed inside your browser and are never uploaded to a server.

How it works

  1. Paste or open the original JSON on the left.
  2. Paste or open the changed JSON on the right.
  3. Review the added, removed and changed keys.

Frequently asked questions

Does key order matter?

No. Objects are compared by key, so reordered keys aren't reported as changes.

Is there a size limit?

No fixed limit — it depends on your device's memory, and there's no daily limit on this tool.

Can I compare two API responses?

Yes. Paste both responses; differences in spacing or key order are ignored, so only real changes in values and structure are listed.
