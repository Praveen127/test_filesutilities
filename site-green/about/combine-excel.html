About Combine Excel

Bring monthly reports, branch files or exports together: keep every sheet in one workbook, or stack rows from files with the same columns into a single sheet, with an optional Source file column. Your files are processed inside your browser and are never uploaded to a server.

How it works

  1. Drop your .xlsx, .xls, .ods or .csv files into the tool.
  2. Choose: keep each sheet, or stack rows into one sheet.
  3. Click Combine and download the workbook.

Frequently asked questions

How do I know which file a row came from?

When stacking rows, tick the option to add a Source file column.

Can I combine CSV and Excel together?

Yes. CSV, XLSX, XLS, XLSM and ODS files can be mixed.
