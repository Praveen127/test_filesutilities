About JSON formatter

Paste or open JSON and it's validated and pretty-printed as you type, with a tree view, key sorting, minifying and a repair option for almost-valid JSON. Your files are processed inside your browser and are never uploaded to a server.

How it works

  1. Paste JSON or open a .json file.
  2. Choose indentation, or Minify, Sort keys or Repair.
  3. Copy or download the formatted JSON.

Frequently asked questions

Is my JSON sent anywhere?

No. Formatting happens in your browser, so API keys and private data in your JSON stay with you.

Can it fix invalid JSON?

Click Repair to have common mistakes fixed automatically, then check the result.

Does it handle large JSON files?

Yes. Files of several megabytes format instantly; very large files (hundreds of megabytes) depend on your device's memory.
