About Data converter

Move data between formats in seconds: CSV to JSON for an API, JSON to Excel for a report, YAML to JSON for a config, or any table to Markdown for documentation. Your files are processed inside your browser and are never uploaded to a server.

How it works

  1. Paste data or open a CSV, JSON, Excel, XML or YAML file.
  2. Choose the output format.
  3. Copy or download the converted data.

Supported formats and limits

Opens
CSV, TSV, JSON, XLSX/XLS, XML, YAML
Creates
JSON, CSV, TSV, XLSX, XML, YAML, Markdown table, HTML table
  • Nested JSON objects are flattened into columns (for example order.id) when converted to CSV or Excel.
  • Workbooks with several sheets: open them in the CSV cleaner, pick the sheet, and export it — the data converter works best with one sheet.
  • Free: this tool has no daily limit.
  • Files are processed on your device, so very large files are limited by your browser and device memory.

Frequently asked questions

Can it convert Excel to JSON?

Yes. Open the .xlsx file, choose JSON and each row becomes an object keyed by the header row.

Does it handle large CSV files?

Yes, within your device's memory, and there's no daily limit on this tool.
